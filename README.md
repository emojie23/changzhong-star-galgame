# 《常中星下，与你相遇》

一款全年龄、纯甜向的单女主网页 Galgame。主角萧楚南与熊莉在开学典礼前偶遇，成为同班同桌，并从九月走到春日星空下的告白。

## 在线游玩

**[点击进入《常中星下，与你相遇》](https://emojie23.github.io/changzhong-star-galgame/)**

游戏通过 GitHub Pages 发布，无需下载安装；首次打开会加载背景图片与配乐，建议使用 Edge、Chrome 或 Safari 的较新版本。

## 运行

双击 `启动游戏.bat`，或直接使用现代浏览器打开 `index.html`。无需安装、无需联网。推荐使用 Edge / Chrome，分辨率 1280×720 以上。

操作：点击对话框、空格或 Enter 继续；底部可回看、存档、读档、自动播放和快进。存档保存在浏览器本地。

## 内容

- 11 个章节、约 230 段对话和 11 次选择，建议普通速度游玩 45–65 分钟。
- 选择影响心动、信赖、默契三项数值与即时回应，但所有路线均为纯甜结局。
- 包含章节回想、对话回看、自动/快进、本地存读档、情景配乐和艺术化校园导览。
- 支持桌面及手机横竖屏布局。
- 5 首本地 CC0 配乐按清晨、日常、雨天、节庆和告白情景自动淡入淡出，默认音量提升至 42%。
- 熊莉拥有 9 张角色图：惊喜、嗔怒、害羞、安静心事，以及运动、冬季、出行和文化节换装。
- “心动、信赖、默契”攻略数值会在关键选择后显示并随存档保存。
- 不同说话者使用不同颜色：熊莉樱粉、萧楚南澄蓝、旁白暖金、同学青绿、系统紫色。

## 资料与虚构声明

熊莉的角色外观参考网络创作者“兔娘”的公开形象特征，游戏中的同校经历、人物关系、对白与事件均为艺术化虚构，不代表本人经历或观点。生成阶段使用的公开参考图不随游戏分发；游戏内角色图为原创 AI 插画。

校园场景依据公开资料进行叙事化近似设计，不是校方正式地图或测绘级复刻，也不包含校园安防与精确室内信息。参考包括：

- [常州市教育局：局属学校信息](https://jyj.changzhou.gov.cn/html/jyj/2020/JNFEPQJQ_1103/108949.html)：学校位于常州市罗汉路 8 号。
- [阳光高考：江苏省常州高级中学学校概况](https://gaokao.chsi.com.cn/zx/sch/zxgkinfo.action?id=178383895)：1907 年创办及办学历史。
- [公开校园风景页](https://www.gx211.cn/school/schoolcontent.aspx?e=0&schoolid=2970)：用于把握校园绿化与建筑氛围。
- [校园文化公开报道](https://www.jingyingzhi.com/news/4653)：校园位于常州市中心、视线可见天宁寺塔等地域特征。
- [兔娘公开视频页面](https://www.bilibili.com/video/BV1rno3Y7EBG/)与[公开人物介绍](https://shandian.biz/175.html)：只用于确认网名和稳定视觉风格；未把低可信人物经历写入剧情。

两杰广场根据用户提供的现场照片重新绘制，保留浅色双人半身像、深红色基座、红色盆花、黄色花带和两侧修剪绿植。教室、操场、图书馆、钟楼露台、文化节夜景、青果巷与星空看台均使用独立背景，不再重复校门图调色。

“常中星”在游戏中作为文学意象使用；天体命名信息来自公开学校资料和公开百科条目。

## 美术生成说明

- 校园背景：内置 imagegen，原创宽屏视觉小说背景。
- 熊莉立绘：内置 imagegen，基于公开外观参考生成的原创二次元角色图。
- 表情与换装：内置 imagegen，以基础立绘锁定人物身份后生成 8 个一致性变体。
- 最终生成提示分别要求：常州市中心江南校园、红砖石柱校门、树梢后的天宁宝塔；以及黑色长直发、齐刘海、黑白发饰、大眼妆感、端庄水手领校服、兔子笔记本、无性暗示。

## 审核剧情

[剧情纯文字审核版](剧情纯文字审核版.md)由游戏脚本自动导出，包含全部 11 章、旁白、对白、选项及两条分支回应。修改游戏剧情后运行 `node tools/export_story.js` 即可重新同步。
